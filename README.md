# 🇫🇷 Персональный ассистент по поиску работы во Франции (Тарб / 65000)

Специализированная система автоматического мониторинга французских вакансий в режиме реального времени (регион Тарб / 65000).

---

## 🌟 Возможности системы

1. **Абсолютный охват источников во Франции:**
   - **France Travail** (бывший Pôle Emploi) — государственная база;
   - **HelloWork** — крупнейший региональный агрегатор;
   - **Meteojob** — поиск по вакансиям вокруг Тарба;
   - **Distrijob** — профильный сайт ритейла и супермаркетов (E.Leclerc, Intermarché, Aldi, Grand Frais);
   - **Adzuna France** — мета-поисковик;
   - **Leboncoin Emploi** — локальные объявления в регионе 65000;
   - **Агентства Intérim** — Adecco, Manpower, Randstad, Crit, Proman в Тарбе.

2. **Персонализированный AI-анализ (Google Gemini):**
   - Учитывает опыт работы в **Grand Frais Tarbes** и **E.Leclerc Ibos**;
   - Контролирует ограничения по мобильности: предупреждает, если для вакансии требуется **Permis B / личный автомобиль** (у Ханны указан велосипед);
   - Автоматически составляет готовый, вежливый текст сопроводительного письма (**Message d'accroche / motivation**) на французском языке под каждую конкретную вакансию.

3. **Мгновенные уведомления в Telegram:**
   - Прямая ссылка на отклик в один клик;
   - Кнопка «В избранное» для сохранения предложений;
   - Исключение повторов (база SQLite помнит все отправленные вакансии).

## 🚀 Быстрый запуск на вашем компьютере

### Шаг 1: Настройка ключей в файле `.env`
Откройте файл `.env` в папке проекта и укажите:
1. `TELEGRAM_BOT_TOKEN`:
   - Напишите в Telegram боту **@BotFather**
   - Отправьте команду `/newbot`
   - Придумайте имя (например, `Hanna Job Hunter`) и юзернейм (например, `hanna_tarbes_jobs_bot`)
   - Скопируйте выданный токен в `.env`
2. `GEMINI_API_KEY`:
   - Перейдите на бесплатный сервис [Google AI Studio](https://aistudio.google.com/)
   - Нажмите **Get API Key** -> **Create API Key**
   - Вставьте ключ в `.env` (если ключа нет, система использует встроенные шаблоны текстов).

### Шаг 2: Запуск бота
В терминале в папке проекта выполните:
```bash
python main.py
```
После запуска откройте вашего бота в Telegram и отправьте команду `/start`.

---

## 📱 Команды Telegram-бота

- `/start` — регистрация и главное меню со статусом поиска
- `/check_now` — принудительно запустить поиск по всем сайтам прямо сейчас
- `/status` — статистика найденных и сохранённых вакансий
- `/settings` — изменить радиус поиска (10, 15, 20 или 30 км)
- `/profile` — просмотр данных резюме соискателя
- `/favorites` — список сохранённых вакансий
- `/pause` и `/resume` — временная приостановка и возобновление мониторинга

## ☁️ Запуск в облаке (GitHub Actions)

Если вы не хотите держать ноутбук включенным, в проекте уже настроен файл `.github/workflows/job_monitor.yml`:
1. Загрузите проект в ваш GitHub-репозиторий.
2. В настройках репозитория (*Settings -> Secrets and variables -> Actions*) добавьте Secret:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID` (ваш ID чата, бот покажет его при `/start`)
   - `GEMINI_API_KEY`
3. GitHub Actions будет бесплатно проверять новые вакансии каждые 15 минут круглосуточно.
